# ADR-004: Use CodeMirror 6 instead of Monaco

- **Status:** Accepted
- **Date:** 2026-11-19
- **Source:** `docs/BUILD_LIST.md` §4.1 (contested point 1), §20 (D6, D27), §1.7

## Context

The visualizer needs a code editor. Monaco's headline feature is IntelliSense, but our sandbox
deliberately supports only a subset of JavaScript: autocompleting `async`/`class`/`yield` would suggest
constructs the engine cannot run. We would therefore be paying a large bundle cost for a feature we
switch off, while two explicit Definition-of-Done targets — accessibility and large-file performance —
are at stake.

## Decision

Use **CodeMirror 6** (§4.1 point 1, D6), delivered as individual packages (`@codemirror/state`,
`@codemirror/view`, `@codemirror/language`, `@codemirror/commands`, `@codemirror/autocomplete`,
`@codemirror/lint`, `@codemirror/search`, `@codemirror/lang-javascript`, `@codemirror/theme-one-dark`,
`@lezer/highlight`). Replace generic IntelliSense with **engine-aware autocomplete** that only suggests
builtins the sandbox can actually run (D27).

## Consequences

- **Positive:** "~250 KB" instead of "~1 MB", better large-file performance, "materially better
  screen-reader support (both are DoD targets)", and Lezer gives total control of diagnostics. The
  editor teaches only constructs the engine can execute, which is a better learning experience than
  Monaco's generic completion.
- **Negative:** about two extra days of work versus dropping in Monaco (§4.1), and the engine-aware
  completion list has to be maintained as the engine's supported builtins grow.

## Alternatives considered

- **Monaco Editor.** Its IntelliSense "actively conflicts with our engine's supported subset" and it
  costs ~1 MB with weaker a11y; using it while disabling its main feature is a compromise (§1.7).
- **Plain `<textarea>` (legacy).** No syntax highlighting, no diagnostics, no accessibility affordances —
  the current state the rebuild exists to fix.
- **Ace / other editors.** Do not offer Lezer-based diagnostics control or the same accessibility
  story; not worth evaluating against two DoD targets.
